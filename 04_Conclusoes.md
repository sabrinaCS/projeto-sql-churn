## Conclusão

Este projeto foi desenvolvido como parte do meu processo de aprendizagem em SQL e Análise de Dados.
Como estudante de Tecnologia em Banco de Dados, busquei aplicar conceitos como filtragem, agregação, ordenação, agrupamento e funções de agregação em um cenário real de negócio.
Embora seja um projeto de nível inicial, ele representa minha evolução prática na utilização do SQL para responder perguntas de negócio e extrair informações relevantes de uma basede dados.
Pretendo expandir este portfólio com novos projetos, utilizando consultas mais avançadas e outras ferramentas de análise de dados, como Power BI e Python.
